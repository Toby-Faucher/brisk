Brisk, round 1b: bento with shaders

Accent

Every card has the same smoke in your accent color, and it only appears while you hover or focus the card. Only the faint one behind the whole window runs all the time. These are hand-written approximations of shaders.com effects; the real build would use the library itself. Try Off / Subtle / Bold.

Sample data. On the Stream screen every shader would be switched off completely so video latency is untouched. Shaders also render at reduced resolution and pause when this tab is hidden.
