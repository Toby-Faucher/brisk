# Brisk UI v1 Implementation Plan

Done and merged. Archived; kept for history.

Status: DONE (UI shipped and deployed, see docs/plans/archive/overnight-2026-10-26-report.md). The task checkboxes below were not ticked.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the one-page stats shell with the approved Brisk dashboard: modular shell, Home bento, Library shelves (all 139 Steam games), Stream with a ghost bar, Machines, minimal Settings, backed by a new host agent on bawn.

**Architecture:** A new Rust binary `brisk-hostd` (user process on bawn, loopback `127.0.0.1:8443`) serves the built Astro page and a JSON API from one origin. It reads Steam (local manifests plus `GetOwnedGames`), reports host status, launches games, and supervises one `brisk-bridge` child per stream, so a quality change is "stop bridge, start bridge with new flags" and the page reconnects to the new WebTransport URL. The page is Astro + Svelte 5 + Bits UI; modules are folders discovered with `import.meta.glob`; the existing `video.ts`/`audio.ts`/`input.ts` move into the Stream module unchanged.

**Tech Stack:** Rust (tokio, a pure-Rust HTTP server such as axum; must pass `scripts/check-pure-rust.sh`), Astro 7, Svelte 5, Bits UI, Geist (self-hosted), WebGL2 GLSL from `research/shaders/ports/`, vitest, playwright-core.

**Spec:** `docs/ui-design.md` (approved 2026-10-25). Also read `docs/m2-notes.md`, `docs/m0-baseline.md`, `research/shaders/README.md`, `docs/ui-mockups/*.html` (open in Chrome; they are the visual target).

7. Existing tests stay green: 62 vitest tests and the Rust workspace. `video.ts`, `audio.ts`, `input.ts` are moved or imported, not rewritten.
8. Quality presets: Fast = 1920x1080@60, 10000 kbps; Balanced (default) = 1920x1080@60, 20000; Crisp = 1920x1080@60, 40000. H.264 only until M3.
9. Wake-on-LAN is out of v1 (the Quick actions card shows a disabled "later" button). Steam is the only library. Phone, gamepad UI, sharing and other modules are out of scope (modules appear as greyed "soon" entries).
10. Heavy work on bawn is capped: `. scripts/capped.sh; cap_check && capped cargo build ...` with `CARGO_BUILD_JOBS=4`; use at most 6 of 20 cores. Sunshine's user unit allows 5 starts per 500 s, so restarts are at least 100 s apart. 11. Copy is friendly and short. Icons are filled and colored per module: Home accent, Library amber, Stream blue, Machines sky, Settings grey, Agents violet, News rose, Workouts green.

## Review Focus

1. A request with a foreign `Host`/`Origin`, or a mutating call without the secret (DNS rebinding, another local process): 403, nothing launched. Test in Task 1.
2. `appid` in `launch`/`install` is not numeric or not in the owned/installed set: 400, never reaches a shell or `steam://` URL. Weird `.acf` files (empty, unicode or quoted names, `StateFlags` not 4 = not fully installed, same game in two libraries): skipped or merged, no panic. Test in Task 2.
3. Steam API unreachable, key file missing, or HTTP 403: Library still lists installed games, `ownedAvailable: false`, UI says "couldn't reach Steam", no key in any output. Test in Task 2.
4. Stream start while one is starting or live, port 4433 busy, bridge exits at once: one bridge at a time (requests serialized), a clear error, state returns to `idle`. Test in Task 4.
5. Reconnect storm and leaving the Stream page: capped backoff, gives up after 5 tries with a "reconnect" button, leaving the page disconnects and releases keys, nothing keeps drawing. Test in Task 9. Also a suspended `AudioContext` (activation lost on navigation) shows a "tap to start sound" prompt instead of silence. Test in Task 9.

Shared types (used by every later task; `web/src/state/api.ts` exports them, hostd serializes exactly these, camelCase):

```ts
type Game = { appid: number; name: string; installed: boolean; sizeBytes: number | null;
              lastPlayed: number | null /* unix s */; playtimeMin: number; cover: string };
type HostInfo = { name: string; sunshine: 'ready' | 'busy' | 'down'; uptimeS: number | null;
                  cpuTempC: number | null; gpuTempC: number | null;
                  path: 'direct' | 'relay' | null; relay: string | null };
type Preset = 'fast' | 'balanced' | 'crisp' | 'custom';
type StreamReq = { preset: Preset; width?: number; height?: number; fps?: number;
                   bitrateKbps?: number; appid?: number };
type StreamInfo = { state: 'idle' | 'starting' | 'live'; preset: Preset | null; appid: number | null;
                    wt: string | null; hash: string | null };
type SessionRec = { appid: number | null; name: string; started: number; ended: number | null;
                    host: string; preset: Preset };
```

Routes: `GET /api/host`, `GET /api/games` -> `{games: Game[], ownedAvailable: boolean}`, `GET /api/stream`, `POST /api/stream` (StreamReq -> StreamInfo), `DELETE /api/stream`, `POST /api/launch {appid}`, `POST /api/install {appid}`, `POST /api/sunshine/restart` (204, or 429 if the last restart was under 100 s ago), `GET /api/sessions` -> `{sessions: SessionRec[]}`. Errors are `{error: string}` with a 4xx/5xx status.
