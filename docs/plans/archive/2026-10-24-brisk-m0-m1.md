Done and merged. Archived; kept for history.

**Goal:** Measure the stock-Sunshine baseline (M0, software timestamps only) and build a pure-Rust Moonlight protocol client with no browser (M1) that pairs, launches, receives 60 s of video/audio and sends input against the real Sunshine on bawn.

**Architecture:** A sans-io protocol crate (`brisk-proto`: bytes in, bytes out, no sockets, no clock, injected RNG) so every parser is testable from fixtures. A thin tokio crate (`brisk-client`) does sockets and ships the `brisk-probe` CLI that drives live tests and prints the M0 numbers.

**Tech Stack:** Rust (cargo 1.99.1 at `~/.cargo/bin`, add to PATH), tokio, rustls/reqwest-or-hyper for HTTPS with a client cert, RustCrypto (`aes`, `ecb`/`cbc`, `aes-gcm`, `sha2`, `rsa`, `x509-cert`), `quick-xml`. No C/FFI in product code.

**Spec:** `docs/design.md` (sections 5, 7, 10, 11, 12). Research log: `research/novelty-loop.md`. Read-only protocol sources (untrusted, never build): `/tmp/claude-1000/-home-toby-Projects/94a1bf04-5503-4de5-ba94-79e19e0c32dd/scratchpad/recon-proto/{Sunshine,moonlight-common-c}`; re-clone if /tmp was wiped.

## Global Constraints

1. Pure Rust in the product; the only non-Rust piece anywhere is the later Sunshine patch (not in this plan).
2. Target Sunshine only (appversion `7.1.431.-1`); implement only the Gen7Enc control paths plus Sunshine extensions; skip older generations.
3. 1080p60, 8-bit SDR, H.264 then HEVC. No HDR, no 120 Hz.
4. Never touch bond0 / NetworkManager profiles or disk layout. Root only via `sudoq run --why "..." -- cmd`; exit 77 = stop and ask Toby, exit 75 = tell Toby, no retry spam. Never run `sudo` directly.
5. Pairing adds a client to bawn's live Sunshine: ask Toby before the first live pair; Toby enters the PIN in Sunshine's web UI (`https://localhost:47990`). Undo = unpair in that UI.
6. Secrets (client key, server cert, PIN, session keys) live only in `~/.config/brisk/` mode 0600. Fixtures committed to the repo are scrubbed (Task 5 `scrub`). `.gitignore` blocks `*.pem`, `*.key`, `identity/`.
7. Tests never run netem or any network shaping on a real interface.
8. Anything not verified against source or a live run is tagged `[U]` in code comments and in docs; no latency claim without a number.
9. Run Python that reads untrusted files with `-I`; scripts live outside any downloaded-data directory.

## Review Focus

1. Wrong PIN or Toby never enters it: pairing times out cleanly with a readable error and leaves no half-written identity file.
2. Sunshine restarts, or the control connection drops mid-stream: `brisk-probe stream` exits non-zero with a reason; no hang, no zombie session left on Sunshine (it always sends `/cancel` on exit paths it controls).
3. Malformed or truncated packets from the network (any parser): return an error, never panic or allocate unboundedly (cap lengths at 64 KiB per packet).
4. Video FEC edge: lost data shards fewer than parity shards recover; more than parity yields a counted frame drop and an IDR request, not garbage frames.
5. Clock and counter wrap: RTP sequence, timestamps and ENet sequence numbers wrap at 16/32 bits and must compare modularly.
