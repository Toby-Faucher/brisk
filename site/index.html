Brisk runs on the PC that has your games and shows them in Chrome on any laptop. There is nothing to install on the laptop, and nothing is exposed to the internet.

Install Brisk

Open source, with more than 800 automated tests.

This is the real app on demo data. Click the sidebar to look around.

Playing from another room usually means another app.

Most game streaming wants a client app on every device, an account, and a few open ports. That is a lot to set up for a laptop you use twice a month.

What you get

Your whole library on one shelf

Installed or not, every game shows up. The last one you played sits on top with a Play button.

The host status at a glance

See if the PC is up, if Sunshine is ready and how hot the GPU runs.

Private by default

Brisk is reachable only over your own Tailscale network. There are no accounts and no open ports.

Controls that stay out of the way

While you play, the screen is only the game. Push the pointer to the top edge to see latency, volume and quality.

Nothing to install on the laptop

Open a page in Chrome. Your keyboard, mouse and gamepad work through the tab.

Your games run on your own PC. The browser is only a window onto them.

Three steps from nothing to playing

  1. Install it on your PC

    Run one command on the Linux machine that has your games. It sets Brisk up next to Sunshine.

  2. Open the page

    Go to the host's address in Chrome over Tailscale. Your library is already there.

  3. Press Play

    The game starts on the PC and shows up in the tab. Move the pointer to the top edge for the controls.

Built in the open

Brisk is one person's project for a home server, and the code is public.

  • The bridge that carries the video is written in Rust.
  • More than 800 automated tests run on every change.
  • The code is MIT licensed. Read it, run it, change it.

Questions people ask

What do I need to run it?

A Linux PC with a GPU and Sunshine, which is the open source game stream host. Tailscale on that PC and on the laptop, which gives you a private network. Chrome on the laptop.

Does it work with a Windows or Mac host?

Not yet. The host side runs on Linux today.

Which browsers work?

Chrome is the one it is built and tested for. Firefox connects and streams, but it is slower.

Is it safe to leave running?

Brisk is reachable only over your Tailscale network, and starting a stream needs a secret that is shown on your own machine. Nothing is opened to the public internet.

What does it cost?

Nothing. It is free and open source under the MIT license.

Which games can I play?

Games from your Steam library, and games from emulators that you add. They all run on your PC, so anything your PC can run works.

Does it support controllers?

Yes. A gamepad plugged into the laptop is passed through the tab, along with the keyboard and mouse.

Is it finished?

No. It is early access, built by one person, so expect rough edges. If you find one, open an issue on GitHub.

Easy to try, hard to regret

Brisk runs as your own user and does not need root. It sits next to Sunshine and leaves your games and saves where they are.
